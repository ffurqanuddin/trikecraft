# TrikeCraft

## Introduction
Welcome to the TrikeCraft, an innovative application designed specifically for disabled individuals. This app aims to provide a seamless and accessible experience for users to order a three-wheel bike tailored to their unique needs.

## Key Features

### Customizable Bike Configuration
- Users can select the engine type (70, 125 or 150), color, number of seats, self-start, reverse, transmission, gear, and more through a user-friendly interface.
- The app displays the corresponding price for each configuration in real-time, allowing users to make informed decisions.
- After selecting the desired options, users can preview the final bike design.

### Order Placement and Tracking
- Users can place their orders directly through the app, specifying the desired delivery time.
- Orders will be in a pending stage until the app admin reviews and approves them.
- Once approved, users can proceed to payment using the app's built-in payment system.
- Users can track the status of their orders within the "My Orders" section.

### Admin Dashboard
- The app includes an admin-only section with a dashboard similar to Amazon's admin interface.
- Admins can manage and organize incoming orders, ensuring efficient processing and fulfillment.

## Technical Details
- The app is built using Flutter, a popular cross-platform framework for building mobile applications.
- The BLoC pattern, a state management solution, is implemented to ensure a scalable and maintainable codebase.
- Firebase Firestore, a NoSQL cloud database, is utilized for storing and managing user orders and other relevant data.
- The app's architecture follows best practices to ensure a robust and scalable design.

## Getting Started
To get started with the project, please follow these steps:
1. Clone the repository to your local machine.
2. Set up the necessary Firebase configurations and credentials.
3. Install the required dependencies using the package manager of your choice (e.g., `flutter pub get`).
4. Build and run the app on your preferred platform (Android or iOS).
